## Context

Kursor custom (dot + ring) punya sistem split warna per-section. Glow dot sudah memakai pola cross-fade yang benar: glow normal di-fade out saat hover, glow hover fade in menggantikannya. **Ring tidak**: border normal tetap tergambar penuh di `#cursor-ring` (background element), sementara ring hover (`::after`, warna alpha 0.45) fade in **di atasnya**. Karena kedua warna semi-transparan, warna normal selalu lolos di bawahnya → border ring hover tampak sebagai campuran kotor dua warna, bukan warna hover murni (mis. tema 1: peach 45% di atas ungu-gelap 45%).

**Fix:** terapkan pola cross-fade yang sama dengan glow dot pada ring — pindahkan gradient border normal ke pseudo-layer yang bisa di-fade out.

## Perubahan — `public/css/style.css` (satu blok, ~baris 4147–4216)

1. **`#cursor-ring`**: hapus `background-image` gradient normal dari element itu sendiri (element jadi container + mask + transform saja). Custom properties (`--pf-ring-a/b`, `--pf-split-y`) tetap ditulis JS ke element dan diwarisi pseudo-elements, jadi tidak ada perubahan JS.

2. **Tambah `#cursor-ring::before`** (baru) = layer ring normal:
   - Gradient `var(--pf-ring-a/b)` dengan `--pf-split-y` (pindahan persis dari background element)
   - `opacity: 1`, `transition: opacity 0.25s cubic-bezier(0.4, 0, 0.2, 1)` (sama dengan layer lain)
   - `::before` otomatis di bawah `::after`, dan mask `radial-gradient` milik `#cursor-ring` tetap berlaku ke kedua pseudo → bentuk cincin 1px terjaga.

3. **Tambah rule hover** di samping rule hover yang ada:
   ```css
   #custom-cursor-canvas.hover~#cursor-ring::before { opacity: 0; }
   ```

`#cursor-ring::after` (layer hover) tidak diubah. Tidak ada perubahan di `public/js/cursor.js`.

## Verifikasi

1. Serve site (Laragon), buka di browser ≤991px excluded — perlu viewport desktop.
2. State normal: ring tampil solid warna section (split warna masih bekerja).
3. Hover di atas link/tombol: ring membesar dan border-nya **murni warna hover** (tidak lagi campur dengan warna normal) — cek minimal 2 tema dengan kontras kuat (tema 1 ungu-gelap/peach dan tema yellow `#ffc107`/putih).
4. Transisi mouseout: ring kembali fade ke warna normal mulus (cross-fade 0.25s, tanpa flash).
5. Cek garis batas antar section saat kursor memotongnya — split warna di `--pf-split-y` masih tegas di ring normal maupun hover.
